# 小日子記帳 V1.4.5

V1.4.5 是 V1.4.4 的資料安全補強版，重點是支援「歷史持股成本待補」與一次性私人匯入。成本未知的持股仍會計入股數、資產配置與股息資格，但不會用 0 元成本製造錯誤報酬率；待補成本完成前，平均成本、損益與 XIRR 會明確顯示「待補資料」。

## V1.4.5 新增

- `costPending`：歷史買進／初始持股可先建立股數，成本之後再補。
- 成本待補仍納入持股與除息資格，但不納入成本／損益／報酬率精算。
- 若成本待補部位已發生賣出，該標的績效會維持待補，避免假精準。
- 私人匯入檔可用 `voided` 撤銷早期誤產生的歷史週期占位資料。
- 投資首頁、持股明細與交易清單會清楚標示「成本待補」。
- 使用者補上成交價並儲存後，該筆自動恢復為可精算交易。

## 升級建議

1. 先在目前版本匯出 JSON 備份。
2. 部署 V1.4.5。
3. 開啟 App 確認資料正常。
4. 再匯入專用的「歷史投資私人合併檔」。
5. 匯入後先檢查投資首頁的「成本待補」與「資料健檢」提示，再逐步補齊未知成本。

資料結構仍為 **V13**；新欄位是向下相容的可選欄位，不需要重建 Vault。
