# 小日子記帳 V1.4.7

V1.4.7 是投資首頁資訊架構重整版，資料結構仍為 V13，不需重新匯入資料。

## 本版重點
- 投資首頁改為總覽型儀表板：資產、年度投報率、持股分布、今年投入。
- 持股清單移至「持股總覽」次頁，改為大卡片與圖像化比例。
- 台股顏色規則：獲利／上漲紅色，虧損／下跌綠色。
- 持股分布比例固定顯示 1 位小數。
- 隱私眼睛改為標準線條 icon，金額預設隱藏。
- 首頁改顯示「今年股息＋老婆分紅」、「今年已實現損益」與「目前未實現損益」。
- 新增「收益分析」：年度股息／老婆分紅比較、期間查詢。
- 股息行事曆移出投資首頁，提醒集中在記帳首頁。
- 最近投資紀錄改為「投入與交易」次頁，提供年度總投入。

## 部署
1. 先備份 App JSON。
2. 將 V1.4.7 內容覆蓋 GitHub 原專案，包含 `functions/api/quotes.js` 與 `_routes.json`。
3. 等 Cloudflare Pages 部署完成。
4. 開啟 App 確認版本 V1.4.7。
