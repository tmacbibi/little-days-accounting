# 小日子記帳 V1.2.1

這是「小日子記帳」第一個正式版。核心仍是：**快速記帳、看懂錢花去哪裡，不做資產餘額管理。**

## V1.2.1 重點

- 高質感生活金流首頁：本月淨流入 Hero 卡、近期支出小趨勢、支出率與投資比。
- 四張互動總覽卡：支出、收入、生活收支、投資可切換首頁視覺分析。
- 支出重點卡：上班餐飲、家庭餐飲、交際應酬等可橫向瀏覽。
- 上班餐飲平均：當月以目前日期天數計算，例如 9/5 直接除以 5；歷史月份除以完整月天數。
- 首頁提醒：待填金額、未來 7 天週期紀錄、預算超支、上班餐飲平均異常。
- 快速輸入模板：內建午餐、停車、家庭餐飲、同事聚餐、電信費、定期投資，可自行新增／編輯／排序／刪除。
- 分析頁圖像化：全年／單月、支出圓環、收入排行、支出排行、投資排行、月／日趨勢與期間比較。
- 日曆視覺標記：支出、收入、投資、待填、未來預定各有不同色點。
- 類別管理：Emoji、名稱、細分類、排序、隱藏、常用類別置頂。
- 語音記帳：同類項目自動加總、不同用途拆筆、草稿可逐筆編輯／移除、一次儲存。
- 金額計算機：支出／收入／投資皆可直接輸入算式，例如 110 + 30 = 140。
- 週期收入／支出／投資：每週、每月、每兩月、每年、起訖日期、多個每月日期、待填金額、未來預定。
- 週期取消：只保留「只刪除這一筆」與「從這一筆開始取消後續週期」。
- 資料安全：6 位數 PIN、Face ID、離開 App 立即鎖定、本機加密。
- 備份與還原：JSON 備份包含記帳、預算、類別、快速模板與週期設定；記錄最近備份時間。
- 更新保護：若最近 3 天沒有備份，按「立即更新」前會再次提醒。

## 版本

- App：V1.2.1
- 資料結構：V9

## 更新方式

1. 先在舊版「設定 → 備份與還原」匯出 JSON。
2. 將本資料夾所有檔案上傳到 GitHub repository 根目錄，覆蓋同名檔案。
3. 等 GitHub Pages 部署完成。
4. 開啟 App；若仍看到舊版本，可在設定執行「檢查新版本／立即更新」。

既有 V0.x 資料會沿用並自動補上 V7 新欄位。

## V1.1.0 新增
- 週期紀錄可選「只修改這一筆」或「從這一筆開始，修改之後所有週期」。
- 從某筆開始修改時，舊週期會在該日停止並建立新週期，過去紀錄保留。
- 新增「個人餐飲」細分類。
- 固定費用新增「薪資扣除」細分類。
- 收入分類新增「技師執業」。




## V1.2.1 隱私安全調整
- 程式碼不再內嵌任何個人歷史收支、薪資、股息或固定扣款金額。
- 私人歷史資料改用本機 JSON 一次性合併匯入，請勿將私人 JSON 上傳 GitHub。
- 已經匯入手機本機的資料不會因更新本版而被刪除。
