# 小日子記帳 V1.4.6

V1.4.6 是投資頁的隱私顯示與資料修復版，資料結構仍為 V13。

## 本版重點

- 投資金額預設隱藏為 `****`，右上眼睛按鈕可切換顯示；App 鎖定後會回到隱藏狀態。
- 目前持股卡片放大「持有股數」，名稱統一顯示「代號 + 中文名稱」。
- 修正「合法 0 成本配股」被誤判為成本待補的問題。
- 私人修復檔可安全刪除舊的占位／待配對資料，不必覆蓋整份記帳。
- 「抓今日股價」新增 Cloudflare Pages 同源代理、原 MIS 直連與官方今日收盤多層 fallback；若仍無資料，會清楚顯示沿用最近收盤價。
- 資料結構維持 V13，原有記帳與投資資料不需 migration。

## 更新方式

1. 更新前先匯出一次目前 JSON 備份。
2. 將 V1.4.6 檔案覆蓋 GitHub 原專案。
3. 等 Cloudflare 完成部署後，開啟 App 確認版本為 V1.4.6。
4. 再匯入配套的「私人修復檔 v4」清掉歷史占位資料。

`functions/api/quotes.js` 是 Cloudflare Pages Function。若目前部署方式不啟用 Pages Functions，App 仍會自動 fallback 到官方公開行情來源，不影響記帳功能。
