# 小日子記帳 V1.4.3

## V1.4.3 安全聯動投資版

這版以「可以開始輸入真實投資資料」為目標，針對 V1.4.2 code review 後的高風險項目進行修正，資料結構升級為 **V12**。

### 1. 安全金鑰可復原

- 舊版 AES 裝置金鑰只存在 IndexedDB，若 IndexedDB 遺失而 Vault 還在，舊版會建立新金鑰，造成舊資料無法解密。
- V1.4.3 起只要偵測到既有 Vault，**絕不靜默建立新金鑰**。
- 首次以 6 位數密碼解鎖 V1.4.3 時，會把舊 Vault 安全搬移到新的可復原主金鑰架構。
- 主金鑰會另以使用者 6 位數密碼衍生的 AES 金鑰加密包裝保存；日常解密仍使用 IndexedDB 中不可匯出的 CryptoKey。
- 若日後 IndexedDB 金鑰遺失但 Vault / PIN 復原包仍在，可使用 6 位數密碼重建裝置金鑰。
- **從 V1.4.2 升級後，第一次請務必用 6 位數密碼解鎖一次，不要先用 Face ID。**完成安全移轉後即可照常使用 Face ID。

### 2. 記帳 ↔ 投資權責規則

- 一般投資記帳先建立 `contribution`：日期、標的、投入金額由記帳資料主導。
- 補齊股數與成交價後，轉為正式 `buy`，由投資帳本成為交易細節的權威來源。
- 正式買進從記帳明細按「編輯」時，會直接進入投資交易編輯器，不允許只在普通記帳表單任意改代號或金額而破壞成本。
- 正式買進仍會同步回記帳頁的日期、代號與實際現金投入金額。
- 股息維持雙向同步。

### 3. 刪除與週期操作增加影響提示

- 刪除已連動投資資料前會明確告知另一邊也會刪除。
- 「只刪此筆」、「從此筆開始停止後續週期」會先提示會影響多少投資帳本資料。
- 從某一期開始修改週期設定，如會重建已存在的投資連動紀錄，也會再次確認。

### 4. 代號自動辨識中文名稱

- 輸入股票／ETF 代號後，自動帶入中文名稱與商品類型。
- 內建常用標的離線資料（0050、0056、00878、00919、00929、00981A、00937B、6446）。
- 其他標的會優先查詢 TWSE / TPEx 公開 API，成功後寫入本機快取。
- 投資明細保存正式中文名稱；持股分布圖則顯示較短簡稱，例如：
  - 0050 元大台灣50 → 台灣50
  - 00919 群益台灣精選高息 → 精選高息
  - 00981A 主動統一台股增長 → 台股增長

### 5. 交易成本自動化

使用者目前券商設定：

- 定期定額買進：**1 元／筆**
- 其他一般買進／賣出：牌告手續費 **0.1425% × 2.8 折**
- 一般交易最低手續費：**20 元**
- 證交稅：賣出時依商品類型自動計算
  - 股票：0.3%
  - 股票型 ETF：0.1%
  - 債券 ETF：依有效日期規則判斷（2026 年底前免徵）
- 預設自動計算；若券商成交單實際費用不同，可勾選「手動調整交易成本」覆寫。

### 6. 新台幣金額一律整數

- 日常記帳金額、投資金額、手續費、證交稅、股息、市值與損益全部以新台幣整數保存／顯示。
- 股價與平均成本仍保留必要小數，以免交易計算失真。
- 報酬率與 XIRR 保留百分比小數。

### 7. 升級相容性

- V1.4.2 的 V11 Vault 可直接升級為 V12。
- 舊 `buy` 會自動標記為正式投資權威資料；舊 `contribution` 保持待補成交資訊。
- 既有 `bookkeepingTxnId` / `investmentLedgerId` 關聯保留。
- JSON 備份／還原仍包含記帳、週期投資、投資帳本、價格與設定。

## 建議的升級測試順序

1. 在舊版先「立即備份」JSON。
2. 部署 V1.4.3。
3. **第一次以 6 位數密碼解鎖**，讓安全金鑰完成移轉。
4. 關閉 App 再開一次，確認 Face ID 可正常解鎖。
5. 用一筆測試用 0050 定期定額完成「記帳同步 → 補股數/價格 → 手續費 1 元 → 雙向修改」。
6. 測試刪除時是否看到投資連動警告。
7. 確認無誤後再開始正式輸入真實投資交易。
