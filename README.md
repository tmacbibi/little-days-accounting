# 小日子記帳 V1.4.8

V1.4.8 是「資產成長與真實報酬版」。資料結構仍為 V13，不需重新匯入既有記帳／投資資料。

## 本版重點
- 修正年度 XIRR：年度期初既有持股改用前一年底市場價值，不再把歷史成本誤當本年度新投入。
- XIRR 可點開查看完整現金流：期初市值、年度買進、賣出、投資股息、期末／目前市值。
- 新增「今年資產成長」：年初投資資產、目前投資資產、資產增加、今年投入、賣出回收、投資股息與投資創造增值。
- 年度邊界股價採最近交易日收盤價，缺資料時自動補抓並快取；不使用過久的舊報價冒充年末價格。
- 持股分布不再合併「其他」，所有持股全部列出，比例固定顯示 1 位小數。
- 個股詳情新增：純報酬率、含息總報酬率、追蹤期間年化 XIRR，以及計算基礎。
- 合法的零成本配股可正常納入股數與成本，不會被誤判為「成本待補」。
- 老婆分紅可納入首頁「今年股息＋分紅」與收益分析，但不會進入股票 XIRR 或單一股票含息報酬率。
- 保留 V1.4.7 的台股紅漲綠跌、期間收益分析、標準眼睛隱私按鈕、持股次頁與投入／交易次頁。

## 重要定義
- 資產總額成長率 = (期末／目前投資資產 - 年初投資資產) ÷ 年初投資資產。這個指標包含持續投入造成的成長，不等於投資報酬率。
- 投資創造增值 = 期末市值 + 賣出淨回收 + 投資股息 - 年度買進投入 - 期初市值。
- XIRR 是考慮每筆現金流實際日期的年化報酬率。

4. 開啟 App，確認版本顯示 V1.4.8。
