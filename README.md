# 小日子記帳 V1.4.10

V1.4.10 是「證券主檔與行情快取版」。資料結構仍為 V13，不需重新匯入既有記帳／投資資料。

## 本版重點

### 1. 新增股票代號 → 中文名稱的官方主檔機制
- 不再靠手工維護完整台股對照表。
- 輸入代號時，先查手機本機快取；沒有資料才查官方市場資料。
- 上市標的使用 TWSE `STOCK_DAY_ALL`；上櫃標的使用 TPEx `tpex_mainboard_daily_close_quotes`。
- 查到後保存 `symbol / fullName / shortName / securityType / market / updatedAt`。
- 本機名稱快取有效 7 天；同一 App 使用期間官方全市場主檔最多載入一次。
- 查不到時只保留代號，不自行猜中文名稱。

### 2. 「更新股價」改成官方收盤優先
- 按下「抓今日股價」時，先查 TWSE / TPEx 官方最新收盤快照。
- 若官方資料已包含今天正式收盤，直接寫入 `priceType=close`。
- 若今天尚未收盤，才 best-effort 嘗試 MIS 盤中價；盤中來源失敗時仍保留最近官方收盤價。
- 正式收盤價與盤中價完全分開，不會互相覆蓋。

### 3. 今日收盤「硬快取」
- 同一證券、同一交易日的正式收盤價只保存一筆（upsert）。
- 只要本機已存在「今天正式收盤價」，再次按更新時**禁止再為該標的呼叫行情 API**。
- 若全部持股今天收盤價都已存在，按鈕會直接顯示「今日收盤價已更新，不重複查詢」，完全不發網路請求。
- 部分標的已有今天收盤時，只查尚未完成的標的。
- App 關閉、重開或重新整理後仍然使用本機持久快取，不會因重開而重抓。

### 4. MIS 盤中代理降級為選用 fallback
- Cloudflare `functions/api/quotes.js` 已補上 session warm-up、`json=1`、`delay=0`。
- 但正式收盤估值與中文名稱解析已不依賴 MIS；即使盤中代理暫時失效，App 仍可使用官方收盤資料。

## 費用與資料安全
- 官方 TWSE / TPEx OpenAPI 不需要 API key。
- 行情以批次全市場快照過濾持股，避免一檔股票打一個 request。
- 所有投資／記帳資料仍保存在使用者裝置端的加密資料庫；GitHub 僅放程式碼。

## 部署
1. 先匯出一次 App JSON 備份。
2. 將 V1.4.10 根目錄檔案覆蓋 GitHub 專案。
3. `functions/api/quotes.js` 若方便可一併更新；**若手機上不方便更新 functions 資料夾，也可以先保留 V1.4.6 之後既有的 quotes.js**，因為 V1.4.10 的正式收盤與中文名稱已不依賴它。
4. 等 Cloudflare Pages 部署完成。
5. 打開 App，確認顯示 V1.4.10。

## 建議驗證
- 新增一檔先前未出現過的上市／上櫃股票，確認輸入代號後能自動帶中文名稱。
- 收盤後按一次「抓今日股價」，確認出現今天日期的收盤價。
- 不關閉 App 再按第二次，應直接提示「今日收盤價已更新，不重複查詢」。
- 關閉 PWA 後重開再按，仍不應重新抓今天已快取的正式收盤價。
