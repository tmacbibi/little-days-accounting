# 小日子記帳 V1.4.1


## V1.4.1 投資視覺改版

- 投資首頁改為圖像化儀表板：目前市值為主視覺，搭配 2×2 摘要卡。
- 新增持股市值分布圓環圖與比例圖例。
- 年度 XIRR 改為圖像化條形比較。
- 最近投資紀錄與持股列表改成更接近原記帳頁的視覺語言。
- 底部導覽精簡為「明細／分析／記一筆／投資」單排四項。
- 「預算」移至設定頁入口；預算功能本身完整保留。
- 本版不變更資料結構，仍為 V10，既有 V1.4.0 投資資料可直接沿用。

## V1.4.0 投資帳本版

- 新增獨立「投資」頁：持股、市值、平均成本、已實現／未實現損益、累積股息與總報酬。
- 支援初始持股、買進、賣出、股息四種投資紀錄。
- 買進會同步到原記帳的「投資投入」；股息會同步到「收入／股息」，避免重複輸入。
- 支援手動記錄現價與歷史價格；年度投報率使用 XIRR 估算，補登年末價格可提升準確度。
- 投資資料納入本機加密狀態與 JSON 備份／還原。
- 資料結構升級為 V10；既有 V9 記帳資料可直接遷移。

## V1.3.5 預算明細版

- 修正 2026 年 1–8 月歷史支出：不再把「歷史變動支出」全部塞進「其他」。
- 依先前整理的信用卡帳單與已確認規則，拆成餐飲、交通、購物、居家生活、娛樂休閒、交際應酬、醫療健康與其他等分類。
- 各月總支出金額維持原值，不會因拆分類而增加或減少。
- 1 月沿用既有歷史估算總額，並依 2–8 月的分類結構拆分。
- 「孝親費」改歸：主類別【家庭】→ 次類別【孝親費】。
- 歷史分類仍標記 historicalSummary，不列入每日平均，也不會塞進日曆每日支出。
- 若再次匯入舊版私人歷史 JSON，App 會自動重新拆成正確分類。

資料結構現為 V10，可直接由 V9 覆蓋更新，既有記帳資料會自動遷移。


- 預算頁每一列皆可點擊，直接查看該用途的細項明細。
