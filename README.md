# 小日子記帳 V1.4.4

## 股息行事曆・持股互動・收盤價快取版

V1.4.4 延續 V1.4.3 的安全金鑰、記帳 ↔ 投資雙向聯動與交易成本規則，新增股息生命週期、可點擊持股詳情、每日收盤價快取、歷史年度收入摘要，以及歷史交易資料健檢。資料結構升級為 **V13**。

### 1. 股息從「一個日期」改成完整生命週期

每筆股息事件可記：

- 股票／ETF 代號與中文名稱
- 除息日
- 每股股息
- 預計入帳日
- 實際入帳日
- 實收金額

`應領股數` 與 `預估股息` **不存死**，每次顯示時都依除息日前的投資 ledger 重新計算。因此補登較早的買賣交易後，後續股息預估會跟著更新。

到預計入帳日，記帳首頁會顯示股息提醒。按「確認入帳」後才會建立／更新正式的 `收入 → 股息`，並與投資股息共用連結；若從記帳頁修改已入帳股息的日期或金額，股息事件也會同步更新。

### 2. 持股配置可以往下點

- 持股分布圖與持股清單都可點個別標的。
- 詳情頁可查看目前股數、平均成本、市值、未實現損益、今年已領股息與累積股息。
- 下方列出該標的的股息事件及歷史交易。
- 資產配置、成本與股息彙總都由 ledger 即時計算，不另外儲存一份容易失同步的 summary。

### 3. 每日收盤價快取 + 主動盤中更新

- 投資頁平常以「最近一個已完成交易日的收盤價」估值。
- App 每個本地日期、每檔持股最多自動嘗試抓一次，不會因重複切頁一直請求行情來源。
- 自動收盤價會優先用 TWSE／TPEx 的全市場端點批次抓取，盡量把多檔持股合併成少量請求；只有批次資料不足時才退回個股歷史查詢。
- 收盤價以 `symbol + marketDate + priceType` upsert，同一天同一檔不會無限 append。
- 升級時也會清理舊版可能留下的重複價格紀錄。
- 「抓今日股價」只有使用者主動按下才抓盤中價；盤中價獨立保存，不覆蓋正式收盤價。
- 抓到盤中價後，投資首頁顯示盤中估值與已更新檔數。
- 手動價格入口仍保留，外部行情暫時不可用時仍能自行補價格。

### 4. 歷史補登沒有資料層日期限制

介面上的使用情境以 2026 年詳細補登為主，但 `investmentLedger` **沒有硬性設定 2026-01-01 邊界**。以後如果找到 2025 或更早的真實交易，一樣可以直接補登。

投資計算原本就是依日期將 ledger 全部重播，所以插入較早交易後，後續持股、平均成本、賣出成本與股息應領股數會自然重新計算。

### 5. 2025 以前可用年度摘要

新增「歷史年度收入摘要」，每年只需填：

- 股息收入
- 老婆分紅

年度摘要不建立假的 12/31 記帳交易，也不進 XIRR：

- 股息收入：可進年度收入與歷年累積股息統計。
- 老婆分紅：只進家庭年度收入，不算投資報酬。
- 同一年若已有年度股息摘要，年度分析與累積股息會以摘要取代該年的逐筆股息，避免重複加總。
- 月度趨勢不會把年度摘要塞進 12 月。

### 6. 超賣不再靜默截斷

舊版持股運算曾可能用可用持股量偷偷截斷超賣股數。V1.4.4 改為：

- 新增／修改交易時若造成超賣，直接拒絕並提示當日實際可用股數。
- 若既有歷史資料已存在超賣，投資首頁顯示資料健檢警告。
- 有問題的賣出不會悄悄套用到持股計算，需先修正歷史資料。
- 若刪除較早買進會造成後續超賣，也會阻止刪除。

### 7. 保留 V1.4.3 既有規則

- AES 主金鑰可用 6 位數密碼復原；既有 Vault 不會因 IndexedDB key 遺失而靜默生成新 key。
- 正式買進由投資帳本管理股數／成交價／費用，記帳頁不能單獨改壞成本資料。
- 記帳與投資仍雙向聯動。
- 股票／ETF 代號會自動辨識中文名稱與簡稱。
- 定期定額手續費：1 元／筆。
- 一般買賣：牌告手續費 0.1425% × 2.8 折，最低 20 元。
- 賣出證交稅依商品類型自動計算。
- 新台幣金額統一整數；股價、平均成本與報酬率保留必要小數。

## 升級建議

1. 在 V1.4.3 先執行一次「立即匯出 JSON 備份」。
2. 部署 V1.4.4 檔案後重新開啟 App。
3. 確認原有記帳、持股與交易都存在。
4. 先新增一筆測試股息事件，確認首頁提醒與「確認入帳 → 收入 → 股息」流程。
5. 點一檔持股確認詳情頁、交易與股息都能展開。
6. 按一次「抓今日股價」確認盤中估值顯示；正式市值仍以收盤價為基準。
7. 若首頁出現「歷史交易需要確認」，先修正超賣資料再大量補登。

> V1.4.4 的 detailed ledger 沒有年份限制；「2026 起詳細、2025 以前年度摘要」是建議的使用方式，不是資料層限制。
